# Interactive Tours (Tutorials)

*Last updated: 01.2025*

The DSA5 system for Foundry VTT offers integrated, interactive tours that guide you step by step through the most important features. These are ideal for beginners to familiarize themselves with the user interface.

## Starting Tours

You can find the available tours in Foundry VTT's **Tour Management**.

1. Open **Settings** (gear icon on the right)
2. Click on **Tours**
3. Select a tour from the list and click **Start**

Alternatively, there are often direct links to the most important tours in the system's **Help Menu** (question mark icon in the chat or settings).

![Tour Selection](images/en-touren-selection.webp)

## Available Tours

The system comes with the following tours by default (the list may vary depending on installed modules):

### 1. Initial Tour (First Steps)
This tour provides a general overview of the DSA5 system's user interface. It shows you where to find things and how basic navigation works.

### 2. Actor Sheet (Character Sheet)
A detailed explanation of the character sheet.
- Explanation of the various tabs (Attributes, Combat, Talents, etc.)
- How to roll checks
- How to modify values

### 3. Library
Shows you how to access the extensive database (compendiums).
- Searching for and finding items
- Looking up rules
- Dragging content onto the character sheet

### 4. Master Menu (GM Menu)
*(Only visible to Game Masters)*
Explains the special tools for the Game Master, such as the GM Menu for managing the group, awarding adventure points, and more.

## Tips

- You can cancel a tour at any time (usually via an "X" or "Skip" button)
- If you get stuck, the tour usually highlights the element you should click with a blinking frame
- Tours can be restarted anytime from the Tour Management
