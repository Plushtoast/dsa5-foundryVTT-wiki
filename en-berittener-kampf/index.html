Mounted Combat

The system supports the rules for mounted combat. To use them, follow these steps:

Mounting

  • Select both rider and mount using a selection box or Shift+Click (e.g., Allacaya and her loyal ogre).
  • Now right-click on the rider. The Token HUD appears.

  • If you did everything correctly, you’ll see a horse icon in the upper left of the Token HUD. Click on it.

  • The rider is now automatically placed on the horse, receives the “riding” status, and is now linked to the mount. The size of the rider may be adjusted so that both rider and mount remain visible.

  • Alternatively, you can assign a mount to a character by dragging and dropping it onto the rider’s character sheet. This way you can, for example, prepare enemy cavalry units in the sidebar. A rider will automatically be placed on the battlefield with their mount if both were linked in this manner.

Dismounting

  • Open the Token HUD of the rider and click on the flipped horse icon to dismount.
  • Alternatively, you can dismount via the trash can icon on the combat tab of the character sheet.

Adjusting Speed and Movement

The speed can also be adjusted according to the rules via the Token HUD or the character sheet. This sets the corresponding check modifiers.

You can move the pair by moving the rider on the battlefield. The mount follows automatically.

Riding Checks and Modifiers

A mounted combatant automatically receives all corresponding bonuses. For example:

  • Advantageous position against infantry
  • Reduced encumbrance
  • The speed of the horse
  • Penalty on dodge
  • The option to roll for the mount’s loyalty (if it has this skill)

You may need to manually trigger riding checks according to the rules.
