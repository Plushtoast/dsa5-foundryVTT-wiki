# Foraging

This function requires the Compendium I module and is only available to the Game Master.

You can find this function via the module's macro compendium or via the GM hotbar.

![Foraging](images/en-nahrungssuche-1.webp)

Follow these steps to start a foraging or hunting session:

* Open the function, for example by clicking on the corresponding icon in the GM hotbar.
* Choose Foraging or Hunting, and set the appropriate modifiers.

![Foraging](images/en-nahrungssuche-2.webp)

* Start the process by clicking on the respective button.
* Messages are now posted in the chat that guide the players through the process. Simply follow the individual steps.
* Players may have corresponding choices for modifiers and decisions during the search.

![Foraging](images/en-nahrungssuche-3.webp)

* On success, the corresponding rations are displayed at the end. These can be added to a player via drag & drop from the chat card.
