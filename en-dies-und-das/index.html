Tips and Tricks

Here you’ll find useful tips and tricks to help you work with the DSA5 system more efficiently.

Keyboard Shortcuts

The DSA5 system offers handy keyboard shortcuts for quick access to frequently used functions:

Key Function Permission
M Open GM Menu Game Master only
J Open Journal Browser Everyone
L Open Library Everyone
B Quick Attack Dialog Everyone
N Next Turn in Combat Active Combatant
V Previous Turn in Combat Active Combatant

Tip: You can customize the keyboard shortcuts in the Foundry settings under “Configure Controls”.

Showing Journal Images

With a right-click on images in item sheets, character sheets, and journals, you can highlight and enlarge the image to then show it to other players. Very useful for Theatre of the Mind in adventures.

Drag & Drop Tips

The DSA5 system supports extensive drag & drop:

Items

  • Library → Character Sheet: Adds the item to the character
  • Character Sheet → Character Sheet: Trades or transfers items between characters
  • Chat → Character Sheet: Take loot directly from dice results
  • Item → Scene: Places the item as a token on the battlefield

Spells and Abilities

  • Spell → Hotbar: Creates a macro for quick access
  • Skill → Hotbar: Creates a check macro
  • Weapon → Hotbar: Creates an attack macro

Creatures

  • Creature → Character Sheet: Starts shapeshifting (requires appropriate modules)
  • Creature → Player Menu: For summoning

Right-Click Menus

There are helpful right-click menus in many places:

  • Token: Quick access to actions, status effects
  • Chat Messages: Compare dice results, apply damage
  • Status Effects: Delete or edit effects
  • Items in Inventory: Equip, Edit, Delete

Quickly Entering Modifiers

For checks, you can enter modifiers in various ways:

  1. Dialog Field: Use the modifier field in the check dialog
  2. Shift-Click: Hold Shift while clicking on a check to skip the modifier dialog
  3. Ctrl-Click: Opens advanced options

Token Hotbar

The Token Hotbar shows context-dependent actions for the selected token:

  • Quick attacks with equipped weapons
  • Frequently used spells and skills
  • Set status effects

More on this at Token Hotbar.

Did You Know?

  • Double-click on Dice Result: Shows details of the check
  • Whisper Chat Messages: Use /w [playername] before your message
  • Secret Rolls: The Game Master can roll secretly with /gmroll or via the check options
  • Autocomplete: Type /sk + Tab for skill name suggestions in chat

Solving Common Problems

Check Doesn’t Work

  • Make sure a token is selected
  • Check if the skill/spell is assigned to the character

Damage Is Not Applied

  • The target token must be marked before the attack (T key or double-click)
  • The attacked player must roll the defense

Effects Are Not Displayed

  • Check in the status tab if the effect is active
  • Some effects require certain conditions
