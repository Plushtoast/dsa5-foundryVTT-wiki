## How to Create Images

### Technical Requirements
- Format: WebP
- Location: `de/images/`
- Naming: `de-[pagename]-[description].webp`
- Resolution: Recommended 800-1200px width
- Include visual highlights (arrows, boxes) where helpful
- **Skin:** Use immersive skin

### Content Guidelines
- Use German UI language
- Use example characters with appropriate names
- Avoid personal/sensitive information
- Show clear, uncluttered interfaces
