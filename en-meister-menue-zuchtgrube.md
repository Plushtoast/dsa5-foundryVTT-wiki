# Breeding Pit

The Breeding Pit is only available through the purchase of the "Master's Workshop" module. Only when the module is activated are these functions available.

1. NPC Breeding: NPC generator that can also create merchant NPCs.
2. Pubs and Taverns: Generator for pub and tavern actors.
3. Loot: Generator for all kinds of loot (chests, bags, etc.).
4. Aventurian Names: Name generator.

![Breeding Pit](images/en-meister-menue-zuchtgrube.webp)  
  

## 1. NPC Breeding

1. Random generator for the various sections. The top die rolls all sections below it randomly once.
2. Basic data of the NPC: Name, Aventurian Names (name source for random names), Gender and Noble (symbols), Species, Culture, Profession.
3. Random variation of various values. This takes into account whether a culture or profession already increases a value. This assigns even higher values in skills, spells, and liturgies.  
The last item "Weapons" gives the NPC weapons they will use themselves.
4. This section is especially interesting for merchants but can also be used to equip an NPC with random equipment.  
The equipment package contains fixed items matching the package name.
5. Here you can set the NPC's money or randomly determine it by clicking on the respective coin.
6. The Token (Folder) indicates which images are available on the right side of NPC Breeding (8). When a token is selected there, the token name becomes visible in Token (File).  
Tip: If Token (File) shows `*.*`, a random token from the Token (Folder) will be chosen when dragging the actor onto the scene.
7. "Link with Actor" connects the token with the actor so that damage is transferred to the actor, etc. "Merchant" automatically selects the [NPC Merchant Sheet](en-haendler#merchant) for the NPC.
8. Selection of the image that will be used for portrait and token of the created actor.

![NPC Breeding](images/en-meister-menue-zuchtgrube-npc.webp)  

## 2. Pubs and Taverns

1. Random generator for the various sections. The top die rolls all sections below it randomly once.
2. Selection of various values for the pub/tavern. Much of this is recorded in the notes of the generated actor after generation.
3. Via "Alcohol" you can set which beverages the actor should be equipped with. This is determined by the region where the beverages are popular.
4. The Token (Folder) indicates which images are available on the right side (5). When a token is selected there, the token name becomes visible in Token (File).  
Tip: If Token (File) shows `*.*`, a random token from the Token (Folder) will be chosen when dragging the actor onto the scene.
5. Selection of the image that will be used for portrait and token of the created actor.

![Pubs and Taverns](images/en-meister-menue-zuchtgrube-taverns.webp)

## 3. Loot

1. Random generator for the various sections. The top die rolls all sections below it randomly once.
2. Name of the generated loot (Alrik's Backpack, etc.).
3. These three buttons change the random equipment depending on selection: Bag, Chest, and no selection.
4. Selection of how much of which equipment type should randomly be present in the loot.  
Additionally, under "Money" you can add an amount to the loot by entry or by clicking on the respective coin. Without input, 1d6 per coin will be placed in the actor.
5. The Token (Folder) indicates which images are available on the right side (6). When a token is selected there, the token name becomes visible in Token (File).  
Tip: If Token (File) shows `*.*`, a random token from the Token (Folder) will be chosen when dragging the actor onto the scene.  
Via "Size", you can then set the token size.
6. Selection of the image that will be used for portrait and token of the created actor.

![Loot](images/en-meister-menue-zuchtgrube-loot.webp)

## 4. Aventurian Names

1. Select a region to be used for generation.
2. Use the die to generate the name.
3. Selection between male, female, and noble names.

![Aventurian Names](images/en-meister-menue-zuchtgrube-names.webp)
