# Currencies

The default currencies can be exchanged via a dedicated setting. Select your own compendium with the corresponding currencies, which will then be added to each new character and used for payment transactions and merchants. Additionally, existing characters can now replace their currencies via the currency context menu. Right-click on any currency on the actor to replace it.

![Currency Setting](images/en-waehrungen-setting.webp)

Money now also has its own subcategory on the item sheet, which determines whether this currency can be used in automatic payment transactions.

![Coin Weight Setting](images/en-waehrungen-weight.webp)

Furthermore, there is also a setting in the settings to count the weight of coins as well, thereby potentially triggering encumbrance on the actor accordingly.
