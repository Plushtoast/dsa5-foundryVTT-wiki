# Enchanting Artifacts

This function requires the Core Rules module.

The Core Rules adds the ability for assisted crafting of artifacts to the system. You can find this function in the Player Menu. This menu can be opened, for example, via the quickbar on the left side of the GUI (found in the DSA Eye Menu).

This function automatically adds the appropriate modifiers to the crafting check, recognizes what equipment the performer has for it (via inventory), and provides several other options.

Follow these steps to craft artifacts:

* Make sure an actor is active in the Player Menu. If none or the wrong one is active, drag the correct actor to the Player Menu via drag & drop. You may need to drag the link symbol on the character sheet next to the name.
* Drag and drop the item you want to enchant from the Library to the Player Menu. Some modifiers will be preset. Alternatively, you can select the appropriate item in the "Artifact" box. The item must be part of the enchanter's inventory.

![Enchanting Artifact](images/en-artefakte-verzaubern-1.webp)

* Select the spell the artifact should contain and all associated settings, and set the charges to be enchanted to at least 1.
* Correct the modifiers if necessary after consulting with the Game Master.
* Perform the Arcanovi check to determine the available QL.
* Cast the chosen spell to determine the FP.
* Adjust all modifiers again if needed.
* Click Finalize to complete the artifact crafting.
* The item has been enchanted. You can find the enchantment in the item's description.

![Enchanting Artifact](images/en-artefakte-verzaubern-2.webp)
