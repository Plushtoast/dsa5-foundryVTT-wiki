# Swarm Rules

A swarm configuration section is integrated into the combat tab of character sheets. Users can now configure the swarm size and base size, resulting in adjusted combat modifiers and life points. This system covers the basic rules for small and tiny creatures and opens up possibilities for tactical encounters with units and soldiers in larger battles, such as the Raven War.

To create a swarm, follow these steps:

* Select all swarm creatures you want to combine on the battlefield (these should be identical creatures)
* Open the Token HUD by right-clicking on the token where the swarm should unite—you should see a swarm symbol

![Swarm](images/en-swarm-1.webp)

* Clicking on this symbol unites the swarm, the swarm's values (e.g., LP) are adjusted and the swarm acts as a single entity.
* Via the token menu, you can also split this swarm again if needed.

![Swarm](images/en-swarm-2.webp)

The swarm size, base size, and all relevant settings can also be configured via the creature's sheet on the combat tab.

![Swarm Configuration](images/en-swarm-3.webp)
