# Brawling

The special rules for brawling are supported.

To start a brawl, start a regular combat and convert it to a brawl using the corresponding button (see image).

![Brawl](images/en-pruegelei-1.webp)

You can also end the brawl using the same button. If actors have received damage, their brawl points will automatically be converted to hit points.

When a brawl is activated, all players receive an alternative health bar, deal only brawl points instead of damage points as damage, and suffer daze instead of pain when hit. Additionally, combat special abilities marked as brawl special abilities only function while a brawl is active.

The rules for this can also be found in the "Master's Workshop" module.

![Brawl Active](images/en-pruegelei-2.webp)
