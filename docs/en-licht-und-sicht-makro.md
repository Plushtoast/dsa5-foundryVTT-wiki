# Light and Sight Macro

The Light Macro is a function that comes directly with the DSA Core Rules module. 
The macro can be accessed either via the GM Menu ([described here](/dsa5-foundryVTT-wiki/en-meister-menue)) or via a macro from the Core Rules compendium.

![Finding the Light and Sight Macro](images/en-licht-und-sicht-makro-find.webp)  

Drag the macro to the macro bar at the bottom, and you can quickly access it with the corresponding key.
  
The macro offers various settings options:  
1. Using "Select Player Tokens" will select all player tokens on the battlefield, so changes can be made for all of them simultaneously.
2. The "Sight" settings offer the option to adjust the sight of selected tokens with a simple click. The values defined under [Presets](/dsa5-foundryVTT-wiki/en-licht-und-sicht-makro#presets) are used.
3. The "Multiplier" is used to quickly adapt the sight to scenes with different visibility conditions using "Multiply" (4).
4. "Multiply" the sight of selected tokens based on the "Multiplier" (3).
5. The "Light" settings offer the option to quickly adjust the light of selected tokens. For example, when players pick up a torch or cast a Flim Flam spell. The settings under [Presets](/dsa5-foundryVTT-wiki/en-licht-und-sicht-makro#presets) are also used here.
6. The "Multiplier" is used to quickly adapt the light to scenes with different visibility conditions using "Multiply" (7).
7. "Multiply" the sight of selected tokens based on the "Multiplier" (6).  

![Light and Sight Macro](images/en-licht-und-sicht-makro-config.webp)

## Presets

In the presets, you can define the defaults for the individual settings in the Sight and Light macro.   
1. Under Sight, you can adjust the settings to match your own playstyle.
2. Using the plus button, you can add more presets that can then be used in the Sight and Light macro. To delete, simply click on Reset (3) at the back.
3. Reset to default values.
4. Under Light, you can adjust the light source settings to match your own playstyle.
5. With the gear icons, you have the option to customize the light settings (brightness, color, animation) to your taste.
6. Using the plus button, you can add more presets that can then be used in the Sight and Light macro. To delete, simply click on Reset (3) at the back.
7. Reset to default values.
8. Via the burger menu button, lights can also be dragged directly onto a scene. You can prepare appropriate lights and reuse them.
