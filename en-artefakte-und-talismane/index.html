Artifacts and Talismans

Artifacts

To equip an item with a spell, drag the spell from a compendium directly onto the item in the equipment menu or directly in the character equipment tab.

  1. If you did this correctly, the Enchantment tab appears in the equipment item.
  2. Clicking on the name of the enchantment opens it with description and details.
  3. Use the die to perform the spell check.
  4. Here you enter the skill value of the spell.
  5. Mark as Permanent: Clicking on the cross changes it to a checkmark and declares the spell as permanent.
  6. Number of charges. If the spell is not permanent, it disappears completely after the check. If it is permanent, only the field is emptied here and can be recharged with a click.
  7. Use the trash icon to delete the spell.

You can also perform this process via the corresponding rule mechanics. See Enchanting Artifacts.

Talismans

To create a talisman, drag a liturgy from a compendium onto an item in the equipment menu or directly in the character equipment tab.

  1. If you did this correctly, the Talisman tab appears in the equipment item.
  2. Clicking on the name of the liturgy opens it with description and details.
  3. Use the die to perform the liturgy check.
  4. Liturgies have a default skill value of 18 when dragged onto an item. However, this value can be changed.
  5. Unlike spells, liturgies are initially always activated as permanent on the item. Clicking on the checkmark deactivates this.
  6. Number of charges. If the liturgy is not permanent, it disappears completely after the check. If it is permanent, only the field is emptied here and can be recharged with a click.
  7. Use the trash icon to delete the liturgy.

If you own the Core Rules, you can additionally trigger an artifact creation check with the associated modifiers via the Player Menu. See also Enchanting Artifacts.
