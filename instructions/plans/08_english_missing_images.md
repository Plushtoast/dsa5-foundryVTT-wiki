## Screenshot Workflow

### Preparation
1. Set Foundry VTT to **English** language
2. Enable **immersive skin**
3. Ensure all premium modules are active
4. Create test characters with English names

### Taking Screenshots
1. Capture at consistent resolution (1920x1080 recommended)
2. Crop to relevant UI element
3. Add visual highlights if needed (arrows, boxes)
4. Save as WebP format
5. Use naming convention: `en-[page]-[description].webp`

### Organization
1. Place all images in `en/images/` folder
2. Update markdown files with correct image paths
3. Cross-reference with German images for consistency
