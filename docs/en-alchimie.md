# Alchemy

This function requires the Core Rules module.

The Core Rules adds the ability for assisted crafting of items through alchemy to the system. You can find this function in the Player Menu. This menu can be opened, for example, via the quickbar on the left side of the GUI (found in the DSA Eye Menu).

This function automatically adds the appropriate modifiers to the crafting check, recognizes what equipment the performer has for it (via inventory), and provides several other options.

Follow these steps to craft potions through alchemy:

* Make sure an actor is active in the Player Menu. If none or the wrong one is active, drag the correct actor to the Player Menu via drag & drop. You may need to drag the link symbol on the character sheet next to the name.
* Drag and drop the brew you want to craft (category: consumable) from the Library to the Player Menu. Some modifiers will be preset.

![Alchemy](images/en-alchimie-1.webp)

* Correct the modifiers if necessary after consulting with the Game Master.
* Click Finalize to trigger the check.

![Alchemy](images/en-alchimie-2.webp)

* On success, a chat message appears with the new brew and its quality level. This can be added to the character via drag & drop from the chat card.

![Alchemy](images/en-alchimie-4.webp)

* On failure, there may be negative consequences. These are drawn from a roll table and displayed to the Game Master.

![Alchemy](images/en-alchimie-3.webp)
